### ALGO-000031: NP versus UP
- **Subfield:** Structural complexity
- **Open:** Determine whether every NP language has an unambiguous polynomial-time verifier: at most one accepting witness for each input.
- **Status:** Open since the 1970s. Valiant–Vazirani provides randomized isolation into unique-solution promise problems, not an unconditional equality of NP and UP.
- **Type:** theory
- **Why:** Clarifies whether ambiguity is an essential source of computational difficulty.
- **Key works:** Valiant and Vazirani (1986), *NP Is as Easy as Detecting Unique Solutions*, DOI: 10.1016/0304-3975(86)90135-0.
- **Related:** Cryptography—one-way permutations; mathematical logic—unique-witness proof systems.
